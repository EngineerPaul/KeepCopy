# Фильтры-исключения в Архиваторе

Фильтры (исключения) задают шаблоны относительных путей **от корня каждого источника**. Файл не копируется, если его относительный путь совпадает хотя бы с одним исключением. Один и тот же набор фильтров действует для всех источников задачи.

## Синтаксис

| Символ | Значение |
|--------|----------|
| `*` | Любое количество символов **без перехода через `/`** (один уровень имени или расширения) |
| `**` | Любое количество символов **с переходом через директории** (рекурсивно) |
| `/` или `\` | Разделитель директорий (при сохранении приводится к `\` в Windows) |

Реализация основана на правилах `gitwildmatch` (библиотека `pathspec`).

## Примеры

| Фильтр | Эффект |
|--------|--------|
| `*.tmp` | Все файлы с расширением `.tmp` в корне источника |
| `**/*.tmp` | Все `.tmp` в любых подпапках |
| `**.png` | Все файлы `.png` на любой глубине |
| `*/*` или `*\*` | Все файлы в поддиректориях **первого** уровня |
| `cache/**` | Всё содержимое папки `cache` и вложенных |
| `temp/log.txt` | Конкретный файл по относительному пути |

## Исключение директорий

Если шаблон совпадает с директорией, из обхода исключается вся ветка (все файлы и подпапки внутри).

## Ограничение по размеру

Отдельно от фильтров задаётся **максимальный размер файла** (МБ). Файлы **строго больше** указанного лимита не копируются и не учитываются в общем размере. Файл **равный** лимиту копируется.

## Порядок и дубликаты

Порядок исключений в списке не важен. Дубликаты шаблонов в форме не сохраняются.

## Режим копирования

Фильтры и max size применяются во всех режимах. Режим копирования влияет только на **какие из прошедших фильтр файлы** попадут в копию (по дате изменения), но не на сами правила исключения.

При подсчёте колонки «Общий размер файлов» учитываются фильтры и max size, но **не** учитывается режим копирования и дата последнего запуска.

# Архиватор

Приложение для периодического резервного копирования файлов и директорий на Windows 10+.

## Требования

- Python 3.10
- Windows 10 или новее

## Установка

```bash
cd Archiver
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

```bash
venv\Scripts\activate
python main.py
```

Данные приложения (задачи, настройки, кэш размеров) сохраняются в `settings.json` рядом с программой. Логи — в `backup.log`, ошибки копирования — в папке `errors/`.

## Тесты

```bash
venv\Scripts\activate
pytest tests/ -v
```

## Компиляция

Инструкции по сборке исполняемого файла и настройке автозапуска — в файле `BUILD.md`.

Скомпилированный `Archiver.exe` иногда **блокируется антивирусом или Windows Defender** (ложное срабатывание на неподписанный exe). Добавьте папку с приложением в исключения: **Параметры** → **Безопасность Windows** → **Защита от вирусов** → **Исключения** → папка `Archiver.dist` (см. подробности в `BUILD.md`).

## Документация

- `FILTERS.md` — описание фильтров-исключений
- `BUILD.md` — сборка через Nuitka и автозапуск
- `true_prompt.docx` — актуальное ТЗ по готовому коду (отличия от исходного `prompt.docx`)

### Генерация true_prompt.docx

Файл `true_prompt.docx` создаётся скриптом `scripts/generate_true_prompt.py` на основе реализованного приложения: интерфейс, логика копирования, расписание, автозапуск, сборка, тесты.

```bash
venv\Scripts\activate
pip install python-docx
python scripts/generate_true_prompt.py
```

Результат сохраняется в корне проекта: `true_prompt.docx`.

## Основные возможности

- Несколько источников и задач резервного копирования
- Режимы: сохранять изменения, сохранять слоями, дублирование
- Фильтры-исключения (`*`, `**`)
- Сжатие в ZIP
- Планировщик с периодичностью
- Фоновое выполнение без блокировки интерфейса

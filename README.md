# KeepCopy

Приложение для периодического резервного копирования файлов и директорий на Windows 10+.

## Требования

- Python 3.10
- Windows 10 или новее

## Установка

```bash
cd KeepCopy
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

```bash
venv\Scripts\activate
python main.py
```

Данные приложения (задачи, настройки, кэш размеров) сохраняются в `settings.json` рядом с программой. Логи — в `backup.log`, ошибки копирования — в папке `errors/`.

## Тесты

```bash
venv\Scripts\activate
pytest tests/ -v
```

## Компиляция

Инструкции по сборке исполняемого файла и настройке автозапуска — в файле `BUILD.md`.

Скомпилированный `KeepCopy.exe` иногда **блокируется антивирусом или Windows Defender** (ложное срабатывание на неподписанный exe). Добавьте папку с приложением в исключения: **Параметры** → **Безопасность Windows** → **Защита от вирусов** → **Исключения** → папка `KeepCopy.dist` (см. подробности в `BUILD.md`).

## Документация

- `FILTERS.md` — описание фильтров-исключений
- `BUILD.md` — сборка через Nuitka и автозапуск
- `true_prompt.docx` — полный промпт/ТЗ для воссоздания идентичного приложения (генерируется из кода)

### Генерация true_prompt.docx

Файл `true_prompt.docx` создаётся скриптом `scripts/generate_true_prompt.py`: интерфейс, копирование, расписание, автозапуск, трей, кэш размеров по источникам, сборка, тесты — в форме, пригодной как промпт для создания сервиса с нуля.

```bash
venv\Scripts\activate
pip install python-docx
python scripts/generate_true_prompt.py
```

Результат сохраняется в корне проекта: `true_prompt.docx`.

## Основные возможности

- Несколько источников и задач резервного копирования
- Режимы копирования:
  - **Сохранять изменения** — в одну папку/ZIP: файлы новее последнего запуска и файлы, которых ещё нет в назначении
  - **Сохранять слоями** — новый слой `backup_ДД.ММ.ГГГГ_NNN` с изменёнными и ещё не встречавшимися в назначении файлами
  - **Дублирование** — каждый раз полный слой со всеми подходящими файлами
- Одинаковые правила отбора для ручного («Выполнить») и автоматического запуска
- Фильтры-исключения (`*`, `**`)
- Сжатие в ZIP
- Планировщик с периодичностью
- Фоновое выполнение без блокировки интерфейса
- Автозапуск Windows с работой в трее (см. `BUILD.md`)
